# Design round C3, the frame (C3-01, C3-03, C3-12, O9): the window opens at
# least at 1360x860 even when it was left smaller; no sidebar, the pages in the
# top bar; the app menu has About, Check for Updates and SubVision on GitHub;
# View has Back (⌘[, shown remapped to the keyboard layout; off without a title
# band) and the parameters item only in a narrow window. A batch of a short
# clip, a damaged one and a long clip run from Sub fix: the batch bar on every
# page with one segment per file, then the end-of-batch sheet over Sub fix (no
# jump to Video) with the failed file as a row and the count in the title.
! SRC="$DEMO/sintel_ita_hardsub_demo.mp4"; { head -c 1000000 "$SRC"; head -c $(( $(stat -f%z "$SRC") - 1000000 )) /dev/zero; } > damaged.mp4
