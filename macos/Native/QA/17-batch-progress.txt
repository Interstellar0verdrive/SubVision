# The batch's bar and "Ends around" weigh each file by its duration: a
# first file half as long as the second puts the bar at one third when it
# is over (by file count it would be at half), and the time left for the
# second comes from the seconds per second of video of the first.
! "$STATE/bin/ffmpeg" -v error -i "$DEMO/sintel_ita_hardsub_demo.mp4" -t 27.5 -c copy short.mp4 && cp "$DEMO/sintel_eng_hardsub_demo.mp4" long.mp4
@launch
wait-ready 600
? ^ready
lang it
params fast
inspector-set langHint it-IT
tab process
add $WORK/short.mp4,$WORK/long.mp4
start
? status ready
batch-progress
? ^file 1/2 · weights 2[6-8]\.[0-9]\+55\.0 · fraction 0\.([0-2][0-9]|3[0-3])[0-9] · rate - ·
wait-file 0 600
? ^ok · short.mp4 done
# One third, plus whatever the second file did before this reply (by count: 0.5 or more).
batch-progress
? ^file [12]/2 · weights 2[6-8]\.[0-9]\+55\.0 · fraction 0\.(3[3-9]|4[0-9])[0-9] · rate [0-9]+\.[0-9]{2} · ends [0-9]
wait-batch 900
? ^batch done · done 2 failed 0 stopped 0 skipped 0
params default
