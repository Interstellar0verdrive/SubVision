# Design notes 76, 79 and design round C3 (C3-09, C3-11, boards A0–A3):
# Preview is a page inside Video. It comes over the list from a row (⌘Y,
# Anteprima) with the panel on Bande and View › Back on, finds its 20
# frames by itself (no Find 20 Frames anywhere) and keeps them per video;
# the block (frame, thumbnails in two rows of ten as wide as the frame,
# summary, the two panels as tall as each other) fits the window without
# scrolling, the frame at most 640 pt wide. A search stopped keeps its
# frames and «Riprova» resumes it on the zones left. Try OCR's results stay
# with their frame; a change of a band's own value makes only that band's
# panel stale, the language both. Back returns to the list as it was.
! cp "$DEMO/sintel_ita_hardsub_demo.mp4" "$DEMO/sintel_eng_hardsub_demo.mp4" "$WORK/"
@launch
wait-ready 600
? ^ready
lang it
size 1360x860
params default
inspector-set langHint it-IT
inspector-tab read
add $WORK/sintel_ita_hardsub_demo.mp4,$WORK/sintel_eng_hardsub_demo.mp4
select 1
preview-state
? ^page hidden
menu-dump 4
? Anteprima ⌘Y \|
? Prova OCR su questo fotogramma ⌘T \(off\)
? Video precedente ⌘.* \(off\) \| Video successivo ⌘.* \(off\)
?! Trova 20
menu-dump 5
?! Anteprima
# The row's video, searched by itself; the panel on Bande, Back on.
preview-open 1
? ^ok · sintel_eng_hardsub_demo\.mp4 · searching$
preview-state
? search running.* · panel bands · back on
wait-frames 300
? ^20 frames · 1[5-9] with text
preview-nav
? ^video 2 di 2 · up sintel_ita_hardsub_demo\.mp4 · down off$
menu-dump 4
? Video precedente ⌘[^|]* \| Video successivo ⌘[^|]* \(off\)
?! Video precedente ⌘[^|]* \(off\)
preview-layout
? ^window 1360x860 .* thumbs 2x10 .* · fits$
# No test yet: the panels wait for Try OCR.
preview-state
? test none
try-ocr
? ^ok · reading
wait-ocr 120
? ^bottom ".+"
preview-state
? test done · tests 1
?! stale
# The signs band higher in the panel: only the signs panel is stale (C3-11).
inspector-set ocr.topKeepPct 26
preview-state
? test done stale signs ·
?! stale dialogue
theme dark
capture $OUT/A3-dark.png
? A3-dark.png$
theme light
capture $OUT/A3-light.png
? A3-light.png$
theme dark
# Another frame has no test; back on the first, its test is still there.
frame 2
preview-state
? test none · tests 1
frame 1
preview-state
? test done stale signs
# The dialogue band changed too: both panels stale; the language alone makes both stale as well.
band-set bottom-height 30
preview-state
? test done stale dialogue\+signs
# «Riprova OCR con i nuovi parametri» (⌘T): the test again, nothing stale.
try-ocr
? ^ok · reading
wait-ocr 120
preview-state
? test done · tests [12] ·
?! stale
inspector-set langHint en-US
preview-state
? test done stale dialogue\+signs
inspector-set langHint it-IT
band-set bottom-height 28
inspector-set ocr.topKeepPct 22
# The window's sizes: the frame stops at 640 pt and the block stays centred.
size 1800x1000
preview-layout
? frame 640x[0-9]+ .* · fits$
size 1100x720
preview-layout
? · fits$
# Narrow: the panel retracts as on the list (N1); the block still fits.
size 1000x720
preview-layout
? · fits$
size 1360x860
# The other video with the band's arrow: its frames are searched by themselves; stopped
# halfway they stay, «Riprova» goes on with the zones left (A1).
preview-video up
? ^ok · sintel_ita_hardsub_demo\.mp4 · searching$
stop-frames
? stopped user [0-9]+/20
capture $OUT/A1-dark.png
? A1-dark.png$
retry-frames
? ^ok · searching
wait-frames 300
? ^20 frames
preview-state
? video sintel_ita_hardsub_demo\.mp4 .* complete .* test none
# The first video: its frames and its test are still there (nothing searched again).
preview-video down
? ^ok · sintel_eng_hardsub_demo\.mp4$
preview-state
? complete .* test done
# Back: the list, its selection, the panel's tab as before, Back off.
preview-close
? ^ok · tab process · back off$
preview-state
? ^page hidden .* panel read
bottom-bar
? ^selection 1 
params default
