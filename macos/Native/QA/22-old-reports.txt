# C3 · old reports (report_upgrade.py, ReportBridge.swift): a review report written by 1.0 or by
# a 2.0 build before report v2 opens in the Review page through the copy the engine renders with
# the current template (report.upgrade, in <state>/tmp/reports): the template marker, the legend
# fixed at the bottom, the app's language (English here, Italian after a switch). The review state
# stays next to the original: the edits saved for the old report show in the copy, a new edit goes
# to the same .review.json, "Reset all" reloads the copy, ⌘S writes next to the original; nothing
# else is written there and the original does not change. A report the engine cannot read opens as
# it is, with the neutral note at the bottom. The fixtures are the ones of the Python tests
# (tests/fixtures/old-reports: the old engines' own pages, synthetic data). Captures in both themes.
